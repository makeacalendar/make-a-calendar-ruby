# Online calendar resources

This gem is an offline Ruby library. For interactive browser workflows, the creator also maintains [Make a Calendar](https://make-a-calendar.com/).

- [Monthly calendars](https://make-a-calendar.com/monthly-calendars) provides customizable month pages and printable layouts.
- [Date tools](https://make-a-calendar.com/date-tools) groups business-day, pay-period, shift, and fiscal calculators.
- [Business-day calculator](https://make-a-calendar.com/business-days-calculator) counts weekdays with observed US federal holidays.
- [4-4-5 calendar](https://make-a-calendar.com/445-calendar) documents the site's retail calendar generator.
- [Date converters](https://make-a-calendar.com/converters) covers timestamp and spreadsheet formats.
- [iCalendar generator](https://make-a-calendar.com/ical-generator) builds all-day calendar files in the browser.

These links are contextual resources; the Ruby toolkit uses its own original implementation and does not access the website.
