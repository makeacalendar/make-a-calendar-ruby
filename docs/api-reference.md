# API reference map

Require `make_a_calendar`.

- `MakeACalendar.month`, `MakeACalendar.year`
- `MakeACalendar.business_days_between`, `MakeACalendar.add_business_days`
- `MakeACalendar.federal_holidays`, `MakeACalendar.fiscal_calendar`, `MakeACalendar.to_ics`
- `MakeACalendar::DateMath` for date grids, quarters, date ranges, ordinals, and ISO weeks
- `MakeACalendar::BusinessDays` for iteration and month/year totals
- `MakeACalendar::Scheduling` for pay dates and shift cycles
- `MakeACalendar::Converters` for Unix, Excel, FILETIME, ISO 8601, and ordinal values
- `Calendar#to_json`, `#to_csv`, `#to_html`, and `#to_svg`
- `YearCalendar#to_json`, `#to_html`, and `#to_svg`

See the README and focused guides for boundary conventions and examples.
