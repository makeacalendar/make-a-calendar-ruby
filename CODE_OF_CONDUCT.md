# Contributor Covenant Code of Conduct

We are committed to a welcoming, respectful community. Be considerate, patient, and constructive. Harassment, discriminatory language, personal attacks, and unwanted attention are not acceptable.

Project maintainers may remove, edit, or reject contributions that do not follow this code and may temporarily or permanently exclude contributors for unacceptable behavior. Report concerns privately through the repository's GitHub contact options.

This code applies in project spaces and when someone is representing the project publicly.
